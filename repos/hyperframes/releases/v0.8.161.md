# HyperFrames v0.8.161

Released on 2026-10-15.

Find music beats without launching Chrome. TypeScript projects using NodeNext can now resolve the published package declarations.

## Features

- `hyperframes beats` uses the TypeScript beat tracker through FFmpeg decoding, without Chrome. Studio shares the tracker; low-confidence audio returns no beat grid. The saved beat-file format is unchanged. ([#5634](https://github.com/heygen-com/hyperframes/pull/5634))

## Fixes

- Resolve published TypeScript declarations with NodeNext module resolution across packages. ([#5532](https://github.com/heygen-com/hyperframes/pull/5532))
