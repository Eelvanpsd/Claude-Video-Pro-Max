# HyperFrames v0.8.150

Released on 2026-10-12.

Video frame injection now releases replaced image resources, keeping render memory from growing with every frame. Composition-wide audio effects and scene export fixes also ship in this release.

## Compatibility notes

- A top-level composition root's `data-fx-chain` now processes the whole audio mix. Remove a previously unused root chain if you want unchanged audio. [#5420](https://github.com/heygen-com/hyperframes/pull/5420)
- For engine API users, `injectVideoFramesBatch` assigns temporary image URLs that expire after decoding. Use the original frame source when serializing or reloading the DOM. [#5494](https://github.com/heygen-com/hyperframes/pull/5494)

## Features

- Apply one audio effects chain across the whole composition, after clip and group effects. Set `data-fx-chain` on the top-level root. [#5420](https://github.com/heygen-com/hyperframes/pull/5420)

## Fixes

- Exported video and audio now respect split scenes' in-points and inline scenes' start times, matching their placement in preview. [#5454](https://github.com/heygen-com/hyperframes/pull/5454)
- A scene previewed or rendered alone uses its own master audio chain. [#5474](https://github.com/heygen-com/hyperframes/pull/5474)
- Pitch-shifted exports keep the end of the clip and its effect tail. Bitcrush preview no longer starts with a silent hold after seeking. [#5478](https://github.com/heygen-com/hyperframes/pull/5478)
- Studio history diagnostics include the server status and reason when an edit cannot be recorded as an undo step. [#5489](https://github.com/heygen-com/hyperframes/pull/5489)

## Performance

- Replaced video frames no longer accumulate cached image resources during capture. Engine-owned capture pages also retain less response data for DevTools inspection. [#5494](https://github.com/heygen-com/hyperframes/pull/5494)
- Large audio effects mixes render in windows instead of loading the full mix into the browser. Parameter automation above 2 GiB remains unsupported. [#5474](https://github.com/heygen-com/hyperframes/pull/5474)

## Catalog

- The `product-promo` example no longer fails lint on conflicting CSS and GSAP transforms, allowing its browser audits to run. [#5481](https://github.com/heygen-com/hyperframes/pull/5481)
