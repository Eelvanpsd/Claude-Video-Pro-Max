# HyperFrames v0.8.156

Released on 2026-10-14.

Videos from screen recordings no longer freeze partway through on FFmpeg 8. Segmented renders with several workers start faster when media is slow to load, and long audio mixes do less work. `@hyperframes/inspector` no longer ships agent tools, so harnesses define their own.

## Breaking Changes

- **Inspector:** Stop shipping agent tools. Harnesses now define their own ([abe97f6e4c](https://github.com/heygen-com/hyperframes/commit/abe97f6e4c704d745dccc4012e7adb2644624c5e), [#5570](https://github.com/heygen-com/hyperframes/pull/5570)). `inspect_components`, `query_timeline`, the stdio MCP server and the `componentsTool`, `timelineTool`, `toolContent` and `InspectionTool` exports from `@hyperframes/inspector/live` are gone. The HTTP contract (`POST /inspect`, `/timeline`, `/element-map`) is unchanged, and `InspectRequest` and `TimelineRequest` are now exported so a harness can build its own schema.

## Fixes

- **Engine:** Renders under WSL use the GPU through full Chrome when the headless shell cannot ([9b996059af](https://github.com/heygen-com/hyperframes/commit/9b996059af6530636b5a3eff9bdd2f52480f14d8), [#5574](https://github.com/heygen-com/hyperframes/pull/5574)). It used to fall back to software rendering.
- **Producer:** Start segmented render workers together so slow media waits overlap ([d77b03c24c](https://github.com/heygen-com/hyperframes/commit/d77b03c24cd2e7c855c602fa8c4546f8076a1dca), [#5573](https://github.com/heygen-com/hyperframes/pull/5573)). Each worker used to wait for the one before it to finish loading media.
- **Engine:** Sample VFR video by timestamp so it does not freeze on FFmpeg 8 ([6afcb48395](https://github.com/heygen-com/hyperframes/commit/6afcb48395632b85663b9b9486e1b47fd175f8bc), [#5572](https://github.com/heygen-com/hyperframes/pull/5572)). FFmpeg 8 honours frame durations, so screen recordings with long, overlapping frames held one frame and dropped the rest. Cached frames from older versions are re-extracted.
- **Engine:** Avoid padding every audio mix input ([3de4763d53](https://github.com/heygen-com/hyperframes/commit/3de4763d53de194b4ddc4d5d8f724fe0e3b3ca74), [#5563](https://github.com/heygen-com/hyperframes/pull/5563)). Short clips no longer stay in the mix for the whole composition, so audio work no longer grows with clip count times length.

## Internal

- **Studio:** Run the edit accuracy slice on PRs and the full grid in the merge queue ([9a2c1c6e80](https://github.com/heygen-com/hyperframes/commit/9a2c1c6e80c7f706c39d3a49d6d87dfd8c8814de), [#5566](https://github.com/heygen-com/hyperframes/pull/5566)).
