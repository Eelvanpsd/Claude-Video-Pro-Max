# HyperFrames v0.8.152

Released on 2026-10-13.

Check and snapshot save each run in its own folder tied to the revision it came from, and renders clean up evidence from old revisions. Project history keeps `.hyperframes/video-state.json` current after every edit and records which element each edit targeted. Agents sharing a project can refuse to start while another agent's turn is open (`--exclusive`), end only their own turn (`--who`), and end safely when no turn is open (`--if-open`).

## Compatibility notes

- Default snapshots moved from `snapshots/` to `.hyperframes/artifacts/snapshots/<id>/`. Check reports are written to `.hyperframes/artifacts/checks/<id>.json`. A render also writes `.hyperframes/render-outputs.json`. Anything still reading `snapshots/` will find nothing. [#5522](https://github.com/heygen-com/hyperframes/pull/5522)
