# HyperFrames v0.8.170

Released on 2026-10-18.

Long projects preview with far less memory and long renders finish their audio faster. Sound effects can now come from Openverse.

## Features

- **Media Use:** Source sound effects from Openverse with the bundled library offline ([49671b73dd4](https://github.com/heygen-com/hyperframes/commit/49671b73dd417f7fe0f3c3f500290df18b447cd0), [#5753](https://github.com/heygen-com/hyperframes/pull/5753)).
