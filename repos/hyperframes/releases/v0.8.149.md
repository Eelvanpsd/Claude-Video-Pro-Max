# HyperFrames v0.8.149

Released on 2026-10-11.

Apps can now import `transcribe` and `removeBackground` from `hyperframes/api` and call them as plain functions. They return typed results and throw typed errors, so tools like HyperFrames Desktop no longer need to run the CLI as a child process.

## Features

- **CLI:** New `hyperframes/api` entry that exports `transcribe` and `removeBackground` as importable functions ([943b6512b](https://github.com/heygen-com/hyperframes/commit/943b6512b43b106c79839a977f3bfa4aa115a11d), [#5453](https://github.com/heygen-com/hyperframes/pull/5453)).
