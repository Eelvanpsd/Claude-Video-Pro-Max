# HyperFrames v0.8.157

Released on 2026-10-14.

Renders inside WSL use the graphics card again on Chrome 150 and later. Before, they fell back to slow software rendering.

## Fixes

- **Engine:** Renders under WSL reach the GPU on Chrome 150 and later ([38cfcdd56cd](https://github.com/heygen-com/hyperframes/commit/38cfcdd56cdc1a8125a8e68a3604357a23ce819f), [#5591](https://github.com/heygen-com/hyperframes/pull/5591)). Chrome 150 and later find no GPU while WSLg's `WAYLAND_DISPLAY` is set, so HyperFrames checks again without it and renders that way only when that reaches the GPU.
- **Core:** Keep the colour grade on a graded video's first rendered frame ([95837a3df7](https://github.com/heygen-com/hyperframes/commit/95837a3df7c10199a83fa1bd6ff92eafc2d1e750), [#5575](https://github.com/heygen-com/hyperframes/pull/5575)). This shipped in v0.8.156 but was missing from its notes.

## Internal

- **Studio:** Settle the edit accuracy bench on frames and network, and reuse the producer Chrome ([d9edffa3a4e](https://github.com/heygen-com/hyperframes/commit/d9edffa3a4e766cb97e7beb09efb2682b6ace5fc), [#5571](https://github.com/heygen-com/hyperframes/pull/5571)).
- **Docker:** Pin FFmpeg 8.0.1 in the Docker images and host CI ([692b89b6e50](https://github.com/heygen-com/hyperframes/commit/692b89b6e50c41cd07e36ecc0ec018bc15373d1e), [#5576](https://github.com/heygen-com/hyperframes/pull/5576)).
