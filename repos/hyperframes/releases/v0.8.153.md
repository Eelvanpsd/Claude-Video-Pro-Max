# HyperFrames v0.8.153

Released on 2026-10-13.

`hyperframes check` now stops instead of running forever when a composition script gets stuck. If this happens during startup, the error names the file.

## Fixes

- **CLI:** Stop stuck checks and report the file to fix ([c96099d39a1](https://github.com/heygen-com/hyperframes/commit/c96099d39a12332d5d87bd922b0d7c1b277b9f22), [#5537](https://github.com/heygen-com/hyperframes/pull/5537)). Browser downloads and first launch no longer use up the check's time limit.
