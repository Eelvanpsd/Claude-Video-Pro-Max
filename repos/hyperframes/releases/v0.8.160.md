# HyperFrames v0.8.160

Released on 2026-10-15.

Measure sound timing with the new audio command. This release also improves trimmed-video previews, Windows rendering, Claude usage reporting, history saves, and element picking.

## Features

- Measure audio onsets, peaks, pauses, and loudness with `hyperframes audio`. Project queries report film time, including clip trims and playback rates. Timeline rows now expose `mediaStart` for consumers that map file timestamps into the film. ([#5602](https://github.com/heygen-com/hyperframes/pull/5602))

## Fixes

- Prepare trimmed video frames before preview cuts, reducing flashes of the wrong frame. ([#5633](https://github.com/heygen-com/hyperframes/pull/5633))
- Keep history saves moving when a file changes while it is being copied. ([#5627](https://github.com/heygen-com/hyperframes/pull/5627))
- Show Claude plan spending even when the usage response has no rate windows. ([#5629](https://github.com/heygen-com/hyperframes/pull/5629))
- Let the first Windows render wait for newly installed browser and FFmpeg files to become accessible. ([#5625](https://github.com/heygen-com/hyperframes/pull/5625))
- Select content beneath faint SVG grain and keep page-wide CSS resets out of an element's inspected styles. ([#5628](https://github.com/heygen-com/hyperframes/pull/5628))
