# HyperFrames v0.8.158

Released on 2026-10-14.

`hyperframes init --keep-original` brings a clip into a project as it is, without converting it. Storyboards are now one board of stills, and `check` no longer fails on a busy Windows machine.

## Features

- **CLI:** `init --keep-original` copies a clip as it is, without transcoding ([d65eefad5ed](https://github.com/heygen-com/hyperframes/commit/d65eefad5ed351e9d36d2caeb6049878be0aba85), [#5612](https://github.com/heygen-com/hyperframes/pull/5612)).
- **Skills:** Storyboards are a board of stills with one page format ([6f90ca15a7f](https://github.com/heygen-com/hyperframes/commit/6f90ca15a7fc937d9d6cf3ec289f2a26eca3724f), [#5599](https://github.com/heygen-com/hyperframes/pull/5599)). Agents pose each shot, snapshot it, and lay the stills out on one page, `boards/storyboard.html`, before animating.

## Fixes

- **CLI:** Capture keeps fonts a page declares in its own style block ([4957bf6939a](https://github.com/heygen-com/hyperframes/commit/4957bf6939a34f659070e04b8c355b35e8be0782), [#5609](https://github.com/heygen-com/hyperframes/pull/5609)).
- **CLI:** A killed browser on a busy Windows machine no longer fails `check` ([fe29f157f94](https://github.com/heygen-com/hyperframes/commit/fe29f157f940c9e07768e25089fb5c4c404ad98d), [#5607](https://github.com/heygen-com/hyperframes/pull/5607)). Windows reports the process gone at once but its exit seconds later, and `check` used to stop on that gap.

## Internal

- **Engine:** The warm extraction cache test checks ffmpeg did not run, not the clock ([14e2ccf3bb0](https://github.com/heygen-com/hyperframes/commit/14e2ccf3bb0e93a2b0226ff665bee36b8033f4a2), [#5613](https://github.com/heygen-com/hyperframes/pull/5613)).
- **Engine:** Audio effect tests that start Chrome get the same time as the others ([7744692a464](https://github.com/heygen-com/hyperframes/commit/7744692a464aa740c893251478f383f46148c1ee), [#5608](https://github.com/heygen-com/hyperframes/pull/5608)).
